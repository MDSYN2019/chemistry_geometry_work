# functoolslings

A rustlings-style practice track for Python's `functools` module.

## How to use

1. Open an exercise in `functoolslings/exercises/...`.
2. Fill every `TODO` section.
3. Run the file with Python.
4. Compare with the matching answer in `functoolslings/solutions/...`.

## Suggested flow

- Start with 00-04 for `reduce` and `partial` foundations.
- Continue 05-09 for decorators and comparator helpers.
- Work through 10-15 for caching and `cached_property`.
- Finish 16-31 for dispatching, ordering, and capstone integration.

## Quick check command

```bash
python functoolslings/check.py
python -m compileall functoolslings/exercises functoolslings/solutions
```
