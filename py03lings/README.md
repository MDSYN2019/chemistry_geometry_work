# py03lings

A rustlings-style practice track for Python 3 fundamentals, including intro async exercises.

## How to use

1. Open an exercise in `py03lings/exercises/...`.
2. Fill every `TODO` section.
3. Run the file with Python.
4. Compare with the matching answer in `py03lings/solutions/...`.

## Quick check commands

```bash
python py03lings/check.py
python -m compileall py03lings/exercises py03lings/solutions
```


## Linear programming track (AIMMS-style modeling in Python)

For LP exercises 06-08, install PuLP first:

```bash
pip install pulp
```

These exercises focus on optimization modeling patterns similar to AIMMS, but fully in Python.
