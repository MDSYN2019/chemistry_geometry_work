# py03lings

A rustlings-style practice track for Python 3 fundamentals, async exercises, and object-oriented method drills.

## How to use

1. Open an exercise in `py03lings/exercises/...`.
2. Fill every `TODO` section.
3. Run the file with Python.
4. Compare with the matching answer in `py03lings/solutions/...`.

## Suggested flow

- Start with 00-03 for Python fundamentals.
- Continue 04-05 for async foundations.
- Work through 06-09 for dataclasses and validation.
- Finish 10-15 for practical data engineering patterns (modeling, partitioning, orchestration, governance, and performance).

## Quick check commands

```bash
python py03lings/check.py
python -m compileall py03lings/exercises py03lings/solutions
```
