# Scientific specification

The primary project specification is the separately supplied
`ALDC_Cl_Br_RBFE_Reproduction_Guide.pdf`. Binary files are intentionally excluded from
version control. For local use, place the document at:

```text
docs/ALDC_Cl_Br_RBFE_Reproduction_Guide.pdf
```

The repository-level `.gitignore` prevents that local binary from being committed.
