# Contributor instructions

The separately supplied reproduction-guide PDF is the primary scientific
specification; binary files are not committed to this repository. Preserve raw
coordinate inputs, never fabricate coordinates or simulation/QM results, and keep
later milestones gated by the stated acceptance criteria. Use typed Python, tests,
deterministic outputs, logging for workflows, and explicit scientific limitations.
M0 contains structural inspection only: no Zn parameterization, MD, or FEP.
